Unofficial CWG RPG community tool

Save in game.
Stay up to date.

Your saves belong in the game, not in an upload form. This small tool watches your CWG save folder and sends changed saves to the leaderboard automatically.

Download the uploader ↓ View the leaderboard ↗

Windows 10+ · Linux console · Free and open source

Automatic uploads are on by default, including existing saves. Submissions go to the public CWG leaderboard.

01 / Backups

Keep a backup beyond your PC.

The leaderboard provides backups of the saves you upload. Automatic uploads help keep those backups current as you play and save.

Backups are provided by the leaderboard, not a separate service in this app. Keep local copies of your saves too.

02 / Inventory & standings

Less reuploading.
More playing.

No need to manually reupload saves whenever you want your inventory and standings updated on the leaderboard. While the uploader is running, new saves are sent for you.

Getting started

Start it. Then save as usual.

  1. Download and run

    Use the Windows installer or a portable package. Linux is console-only. You don’t need Go installed.

  2. Choose your save folder

    The Windows tray app finds the usual CWG folder. Console builds need an explicit folder. See setup instructions.

  3. Keep playing

    Leave the app running. When you save in game, it waits for the files to settle and uploads the changed snapshot.

!

Know what gets uploaded

The app sends eligible .pld files directly inside your selected CWG save folder to the leaderboard. It never scans subfolders and never modifies your game saves. Uploads respect settling and safety limits.

Submissions may appear publicly. Read the README before running the app.
